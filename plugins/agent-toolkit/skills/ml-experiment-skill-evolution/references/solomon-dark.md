## Required distinctions

- Sampled training return versus deterministic policy strength.
- Arena ranking/tie-break versus material progression.
- Wave progression versus kill-count tradeoffs.
- Combat-policy learning versus choice/loadout-policy learning.
- Element specialization versus shared-tensor contamination.
- Completed long run versus screened checkpoint winner.
- Experiment checkpoint versus packaged or production checkpoint.

## Skill-evolution invariant

A proposed procedure must retain separate normal element starts, natural
discovery, explicit learned swapping, per-element isolation, deterministic
screening, disjoint holdouts, and the production replacement boundary. It must
not promote a final checkpoint merely because it is newest or start CPU-heavy
training on Windows/WSL.

## High-value recurring patterns

- Sampled reward improvements that disappear under deterministic argmax.
- Death or terminal rewards overwhelming ordinary combat credit.
- Consolidation passes that preserve samples but regress deterministic play.
- Tie-break winners with no wave-depth improvement.
- Wave improvement accompanied by material kill regression.
- Long checkpoint lineages completed before systematic screening.
- Decoder/checkpoint schema mismatch at packaging or production startup.
